SYREN D. CALIBO — PORTFOLIO WEBSITE

OPEN LOCALLY
Double-click index.html in a browser. All pages and the profile image work offline; optional Google Fonts require internet.

PUBLISH FREE
Option A: Upload this entire folder to Netlify Drop at https://app.netlify.com/drop
Option B: Create a GitHub repository, upload the files, then enable GitHub Pages in repository Settings > Pages.

CUSTOMIZE
- index.html: change biography, services, contact and employment details.
- styles.css: colors and typography are at the top.
- blog/: edit the three starter articles in your own voice before publishing.
- assets/syren-profile.png: replace with another portrait if desired.
- Training section: confirm Coursera completion status before describing it as a completed certification.
- Work examples are generalized to avoid disclosing employer/client information.

The website is a static portfolio and does not collect contact form submissions. Email and phone links open the visitor's installed apps.
